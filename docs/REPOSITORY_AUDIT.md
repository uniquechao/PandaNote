# 公开仓库复核记录

日期：2026-10-22。对象：PandaNote 966U2 公开源码与文档。

## 范围与方法

- 从 GitHub 读取当前树、分支、标签与三个历史提交，使用 Git 对象哈希校验本地审计快照。
- 扫描所有公开文件名与文件内容，包括生成 JavaScript、共享夹具、第三方说明和二进制的可见文本。
- 使用 detect-secrets 1.5.0 对当前树及历史快照执行关键词、服务商 token、私钥、基础认证与高熵扫描；禁用网络凭证验证，不尝试使用候选凭证。
- 对扫描候选项逐类复核，区分合成数据、公开完整性摘要、符号和压缩框架代码误报；没有把测试目录整体排除。
- 检查 PNG、WebP 等图片元数据；仅发现一张图片包含颜色空间和尺寸字段，没有发现个人字段。
- 检查 Markdown 相对链接、目标路径、锚点和三端文档矩阵；发布后按远端树逐文件核对。
